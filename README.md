# 青番 · Qingfan

**轻量 Ubuntu 桌面专注钟。一次只专注一件事。**

青番把一个完整的番茄钟浓缩成桌面悬浮时钟：平时只看时间，需要时展开任务面板。没有账号、联网、云同步、报表或复杂项目管理；本地 Python + GTK 3 实现。

## 核心体验

**三个界面、同一套计时状态：**

| 界面 | 用途 | 操作 |
| --- | --- | --- |
| 圆形专注悬浮体 | 看剩余时间、当前任务和轮次；开始/暂停、重置 | 正常默认显示；可拖动定位 |
| 迷你时钟（100 × 100） | 极小常驻面积，减少遮挡 | 点击悬浮体右上缩小图标；单击迷你表盘恢复 |
| 任务清单 | 添加、选择、完成、排序、搜索任务 | 点击悬浮体清单图标，或按 Ctrl+L |

完整悬浮体尺寸 **326 × 356**（逻辑像素）；浅绿透明椭圆主体、环形时间进度，时间、任务名和进度环始终清晰。设置中可将背景透明度调为 **70%–100%**，默认 **90%**，即时预览，点击保存后记忆。

### 第一次使用

1. 打开任务清单，输入任务并回车添加。
2. 点击任务名称选择当前任务；勾选复选框表示完成任务。当前任务以浅绿色背景突出显示。
3. 点击底部 **开始专注**，任务清单自动收起，显示悬浮时钟。
4. 任务较多时，在列表区域滚动浏览；已完成任务默认折叠。

### 专注节奏

- 默认专注 **25 分钟**、短休息 **5 分钟**、连续四次专注后长休息 **15 分钟**。
- 轮次结束后发送桌面通知；每个新阶段均需手动开始。
- 只有完成完整的专注轮次，当前任务的累计番茄次数才加一。暂停、重置、休息不计数。
- 计时运行中不能误切换任务。暂停后切换任务会丢弃当前未完成的一段专注，已完成的轮次不变。
- 计时器是应用的唯一事实源；完整悬浮、迷你和任务面板之间切换不复制、不重新启动计时。

### 鼠标与键盘

| 操作 | 功能 |
| --- | --- |
| 完整悬浮体底部按钮 | 开始 / 暂停 / 继续 |
| 双击悬浮表盘的空白区域 | 开始或暂停 |
| 单击迷你表盘 | 恢复完整悬浮体 |
| 按住并拖动悬浮表盘空白区域（移动约 8px） | 移动悬浮体；不触发计时 |
| 中键按住表盘拖动 | 直接请求窗口管理器移动 |
| 右键悬浮体 | 任务清单、切换大小、开始/暂停、设置、置顶、退出 |
| Ctrl+N | 打开任务清单并聚焦添加框 |
| Ctrl+L | 在任务清单与悬浮时钟之间切换 |
| Ctrl+F | 打开任务名称搜索 |
| Space | 悬浮时钟中开始 / 暂停 |
| Esc | 清除搜索、关闭搜索或收起任务清单；编辑时取消修改 |
| 点击任务名称 | 选择为当前任务；不会自动启动计时 |
| 任务复选框 | 标记完成 / 恢复为待办 |
| 更多操作菜单 | 重命名或删除任务 |
| 拖动柄 | 调整待办任务顺序；也可使用 Alt+↑ / Alt+↓ |
| 任务右侧“🍅 X” | 已完成的专注轮数；计数为零时不显示 |
| 撤销提示 | 完成、恢复或删除任务后，7 秒内可撤销 |

任务清单使用独立的可调整大小窗口，默认约 400 × 520 逻辑像素，最小 360 × 360。标题、添加入口和底部操作固定，只有任务列表滚动。窗口默认最多占屏幕工作区高度的约 72%，并受 620 像素上限约束。待办与已完成任务分组显示，但仍由同一份有序任务数据驱动；搜索不会改变任务顺序。

## 安装 / 更新

Ubuntu **22.04 / 24.04**，优先 GNOME 桌面。依赖系统 Python 3、GTK 3、PyGObject、Cairo 外部类型绑定和 SVG 图标支持，无 Python pip 或前端打包依赖：

```bash
sudo apt update
sudo apt install python3-gi python3-cairo python3-gi-cairo gir1.2-gtk-3.0 librsvg2-common

git clone https://github.com/jiaquan301/qingfan.git
cd qingfan
./install.sh
```

在应用菜单搜索“青番”，或在源码目录运行 `./run.sh`。本地更新：

```bash
cd qingfan
git pull
./install.sh
```

修改源码后必须重新执行 `./install.sh` 更新已安装副本。卸载运行 `./uninstall.sh`；用户任务仍保存在 `~/.local/share/qingfan/state.json`。目前处于未发布开发阶段，不承诺历史版本数据格式兼容。

## 悬浮透明与桌面兼容性

- 使用支持 alpha 的 GTK RGBA 视觉格式和 Cairo/Pango 绘制圆形计时器。**不是**整窗降低透明度：计时文字和进度环保持高对比。
- X11 需要窗口管理器/合成器支持透明混合；不支持 RGBA 时自动回退到不透明浅色背景。
- Wayland 对窗口置顶、自由移动等请求的处理因桌面管理器而异；不能保证所有组合一致。
- 透明区域**不支持鼠标点击穿透**，没有毛玻璃模糊效果，也不会尝试改变其他程序窗口。
- 置顶和背景透明度持久保存。是否真正置顶由系统窗口管理器决定。
- 采用独立管理窗口与独立悬浮窗口，任务管理不再是一直展开在倒计时下方的长列表。

## 项目结构

- `pomodoro/core.py`：任务、轮次、精确倒计时和 JSON 原子保存。
- `pomodoro/app.py`：GTK 应用、任务管理、快捷键、设置和通知。
- `pomodoro/floating.py`：圆形进度环、独立悬浮窗、迷你模式和手势操作。
- `assets/style.css`：任务面板和悬浮操作控件视觉体系。
- `tests/`：纯模型、GUI、安装及交互回归测试。

## 开发与验收

```bash
# 纯模型与可用环境下的 GUI 测试
/usr/bin/python3 -m unittest discover -s tests -v

# 需要 GTK 可用，禁止静默跳过 GUI 验收
./verify.sh

# 代码语法
/usr/bin/python3 -m compileall -q pomodoro tests
```

GitHub Actions 在 Ubuntu 22.04 的 Xvfb + D-Bus 图形环境运行回归测试。自动化验证包含迷你/完整尺寸、窗口间切换、任务计时唯一性、透明度读写、排序、搜索、任务完成与恢复、删除撤销，以及 5、20、50 项任务的长清单滚动。

**发布前仍应在真实 Ubuntu GNOME 的 X11 与 Wayland 中观察实际绘制和桌面行为**，包括圆形透明边缘是否存在黑框、悬浮表盘是否可自然拖动、字体缩放和多屏位置。虚拟显示器中的测试不代表已经进行过真实桌面人工视觉验收。
