# 青番 2.0 · Ubuntu 原生桌面番茄钟

青番是一款轻量的、**以任务为中心**的桌面番茄钟，设计目标是「打开即可开始工作」。只做任务清单、专注与休息，不引入账号、云服务、统计系统或 Electron。

## 安装 / 升级

支持 Ubuntu 22.04 及更新版本（GTK 3）；优先使用 GNOME 桌面。

```bash
sudo apt update
sudo apt install python3-gi gir1.2-gtk-3.0 librsvg2-common
cd qingfan-v2
./install.sh
```

然后在 **Ubuntu 应用菜单搜索「青番」**，也可在解压目录执行 `./run.sh`。安装器将应用复制到 `~/.local/share/qingfan-app`，以后不依赖解压位置。更新到本版**不清除旧数据**：沿用 `~/.local/share/qingfan/state.json`。

### 从 1.x 升级

如果此前从旧目录运行过青番，先退出旧应用，再执行安装脚本；新、旧应用不要同时运行（会竞争写入同一状态文件）。安装器会自动移除旧版的 `qingfan.desktop` 快捷方式（不会删除任务数据）。新应用菜单项为 `app.qingfan.Pomodoro.desktop`。

## 日常使用

- **首次启动**：点击「选择任务」，输入一件要完成的事，回车添加；首个任务自动被选中。
- **专注**：点击「开始专注」，工作 25 分钟；阶段结束后提醒，并转入 5 分钟休息，连续 4 次专注后进入 15 分钟长休息。新阶段须手动开始。
- **任务编辑与排序**：点击任务名称直接编辑，回车或移开焦点保存，Esc 取消；空名称保留原内容。拖动每行的拖柄调整顺序，也可聚焦拖柄后按 `Alt+↑/↓`。复选框标记完成，播放图标选择当前专注任务，垃圾桶直接删除；「撤销」可恢复最近一次删除（关闭窗口后失效）。
- **窗口**：拖动标题栏自由放置窗口，展开列表和修改任务不会主动移动窗口；图钉切换置顶，列表按钮切换紧凑/展开，齿轮打开计时设置。
- **快速操作**：`Ctrl+N` 输入新任务，`Ctrl+L` 展开/收起，`Esc` 收起列表，在非文字输入状态按 `Space` 开始/暂停。
- **计时设置**：通过标题栏齿轮打开「计时设置」，修改 1~180 分钟。正在运行的计时和进度基准不变化，重启后仍保留；未开始的完整阶段会更新，进行过一部分的暂停阶段则重置后应用。
- **关闭/退出**：计时暂停并保存剩余时间；下次启动仍为暂停，不在退出期间偷偷倒计时。

## 设计取舍与桌面兼容性

- **视觉体系**：原生 GTK HeaderBar，系统管理窗口关闭；倒计时最大层级、当前任务次之、操作最少；不复制系统标题栏。展开面板的高度随待办数量变化，任务超过六行后滚动。
- **技术栈**：仅 Python 标准库 + Ubuntu 的 `python3-gi`、GTK 3；本地 JSON + 原子写入，低占用；不依赖网络。
- **X11**：可请求置顶，用户拖动窗口定位；应用不主动贴边或重新居中。窗口管理器仍可调整实际位置。
- **Wayland**：窗口由桌面管理器定位，用户拖动标题栏移动。普通 GTK 3 窗口的置顶请求可能不被桌面支持。
- **字体缩放与无障碍**：使用原生字体渲染、系统缩放、GTK 控件与键盘焦点；较窄尺寸下任务文字省略显示完整悬浮提示。
- **计时基准**：使用截止时刻，不依赖固定间隔减秒；待机恢复后可以正确触发阶段结束。系统时钟被人为修改时仍可能影响当前计时。

## 运行测试

正式发布请在图形桌面终端运行 `./verify.sh`。该检查要求 GUI 可用，不能跳过图形测试；下方普通测试允许在无显示服务环境跳过 GUI 项，不代表发布检查通过。

```bash
/usr/bin/python3 -m unittest discover -s tests -v
python3 -m compileall -q pomodoro
```

请在目标 Ubuntu 图形桌面检查窗口布局、关闭/重启、通知、设置对话框、长任务文本、较多任务列表、鼠标拖动排序、行内编辑、删除撤销、X11/Wayland 自由定位；自动化测试**不能替代真实桌面验收**。

## 卸载

在下载/解压的项目目录运行 `./uninstall.sh`。卸载脚本不会删除任务数据，需彻底清空个人数据时自行删除 `~/.local/share/qingfan/`。

## 数据安全与发布验收

- 数据格式新增可选的 `phase_duration` 字段，旧数据仍可加载。
- 遇到损坏或异常结构的数据时，尽量保留有效任务；首次写回前将原文件备份为数据目录下的 `state.recovery-*.json`。
- 数据无读取权限时提示错误，不用空数据覆盖原文件；保存失败时提示原因，关闭窗口前仍会重试保存。
- GUI 测试需要 GTK 3 图形桌面，无显示服务时会明确跳过。可在桌面终端运行完整测试，或在已有 Xvfb 的环境使用 `xvfb-run -a /usr/bin/python3 -m unittest discover -s tests -v`。
- 发布检查结果及尚未完成的真实桌面验收见 [发布检查报告](docs/release-review.md)。
