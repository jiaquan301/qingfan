# 青番 · Qingfan

**一个为 Ubuntu 设计的轻量番茄钟。一次只专注一件事。**

青番 1.0 只解决两件事：**确定当前任务**、**专注完成一个番茄钟**。无需账号、云服务、网页、Electron 或复杂的项目管理功能。界面采用原生 GTK 3，任务保存在本机。

## 安装与运行

- Ubuntu 22.04 / 24.04（优先 GNOME，X11/Wayland）
- Python 3（系统 `/usr/bin/python3`）、GTK 3 和 PyGObject

```bash
sudo apt update
sudo apt install python3-gi gir1.2-gtk-3.0 librsvg2-common

git clone https://github.com/jiaquan301/qingfan.git
cd qingfan
./install.sh
```

安装完成后在应用菜单搜索 **青番**。不安装也可在代码目录执行 `./run.sh`。修改源代码后，重新运行 `./install.sh` 才会更新已安装副本。

卸载：`./uninstall.sh`。脚本卸载程序但保留用户任务文件，需清空开发数据时手动删除 `~/.local/share/qingfan/state.json`。

## 使用方法

1. 点击标题栏的**任务清单**图标，输入任务名称，按 **Enter** 添加；首次添加的任务自动选中。
2. 点击任务左侧的**方框**可选中任务，同一时间最多选中一项。**方框不是“完成”或“删除”。**
3. 点击 **开始专注** 后计时器工作，任务清单自动收起；点击 **暂停** 可暂停，继续时清单仍保持收起。
4. 一轮专注默认 **25 分钟**。专注完成后按提示休息 **5 分钟**；每完成四轮专注，安排 **15 分钟**长休息。每个阶段都由你点击按钮开始，不强制自动进入下一阶段。
5. 一轮专注自然结束，当前任务的 **番茄次数 +1**；暂停、重置或未完成时不计数。

### 任务清单

| 操作 | 行为 |
| --- | --- |
| 左侧方框 | 选择/取消选择当前任务，仅能选中一项 |
| 点击任务名称 | 行内编辑；回车或点击其他位置保存，Esc 取消 |
| 六点拖柄 | 鼠标拖动改变顺序，或聚焦后按 `Alt+↑ / Alt+↓` |
| `N 次` | 展示此任务已完成的专注轮数，不是计划次数 |
| 垃圾桶 | 删除任务，7 秒内可撤销 |
| 标题栏清单图标 | 手动展开/收起任务列表 |

- 为保持窗口紧凑，任务列表最多显示 **4 行**，其余任务可滚动；长名称只显示一行，悬浮可查看全名。
- 计时进行时，不能切换其他任务；请先暂停。切换任务会**清空当前未完成的专注时间**并从完整时长重新开始，已累计的番茄次数不受影响。
- 删除当前任务会暂停计时，避免后台继续计入不存在的任务。
- 删除撤销只在当前窗口会话及提示可见期间有效。

### 键盘与窗口

- `Ctrl+N`：展开清单并聚焦新任务输入框
- `Ctrl+L`：展开/收起清单
- `Esc`：取消正在进行的编辑，或收起清单
- `Space`：焦点不在可交互控件时开始/暂停计时

标题栏支持置顶切换；点击齿轮可调整专注、短休息、长休息时长（1–180 分钟）。Ubuntu Wayland 是否支持置顶由窗口管理器决定。

## 设计原则

1. **计时优先**：开始工作后只保留时间、任务名称、进度、暂停和重置，不强迫用户面对待办列表。
2. **单一语义**：选择、编辑、排序、删除互不混用；没有每行的第二个“开始”按钮。
3. **明确反馈**：仅完整专注计数；任务切换重置未完成的轮次；删除可短暂撤销。
4. **极简依赖**：系统 GTK 3 + Python 标准库，不联网、不追踪、不发送使用数据。

代码结构：`pomodoro/core.py` 负责计时、任务和原子化 JSON 持久化；`pomodoro/app.py` 负责 GTK 界面；`assets/style.css` 负责外观；`tests/` 包含核心、GUI、安装与回归测试。

本仓库目前处于 **1.0 开发阶段**，数据结构尚未承诺稳定；不提供历史版本迁移保证。

## 开发与验收

```bash
# 核心测试（无 GUI 也可以运行，GUI 测试会提示跳过）
/usr/bin/python3 -m unittest discover -s tests -v

# 完整 GUI 发布验证（必须在图形桌面或 Xvfb 环境运行）
./verify.sh

# 检查 Python 语法
/usr/bin/python3 -m compileall -q pomodoro
```

自动化测试覆盖时间状态机、累计计数、单项选择、编辑、排序、删除撤销及安装行为。GitHub Actions 在 Ubuntu 22.04 的虚拟 GTK 图形环境中执行图形测试；**自动测试通过不等于真实桌面验收**，首次发布前仍应在实际 Ubuntu GNOME 桌面核对显示缩放、鼠标拖放、窗口位置、通知和 X11/Wayland 行为。

### 提交前检查

- 启动后没有空白窗口或仅标题栏现象
- 首次添加任务、选择任务和开始专注流程不超过三步
- 点击非输入区能结束编辑；点击输入框不会错误保存
- 选中项唯一，选择操作不表示完成/删除
- 拖柄可跨多行改变顺序，重启后顺序保存
- 开始专注后任务列表收起，暂停时不意外展开
- 专注结束准确累计到对应任务，休息/重置不计数
- 长任务名、超过四行的任务、删除撤销不会造成窗口溢出
