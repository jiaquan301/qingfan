# 青番 V2｜产品需求与视觉交互规范（正式版）

> 文档状态：产品基线 · 2026-10-20  
> 适用产品：青番 Qingfan Desktop V2 · 首发 Ubuntu 22.04/24.04，架构兼容 Windows/macOS  
> 优先级：P0 为发布阻断，P1 为正式版体验要求，P2 不纳入首发。

## 0. 一句话产品定义

**青番是一只安静、精致、随手可用的桌面番茄钟。打开即开始，任务可选，不打扰当前工作。**

首要体验：用户从看到表盘到开始计时不超过一次点击。青番不能变成缩小版的项目管理工具。

### 北极星指标（通过可用性测试衡量，不假定已达成）

- 从启动完成到首次开始计时：中位数不高于 3 秒（不含应用冷启动耗时）。
- 从看到主界面到开始计时：一次点击，无必填任务。
- 新用户不用说明书，10 秒内能指出开始/暂停区域。
- 迷你态长期常驻，不遮挡正文，能在 1 秒内看清时间。
- 第一次安装时不弹出任务、设置、欢迎引导或其他窗口。
- 无任务、网络断开、最小尺寸和 50 项任务，产品都可完整使用。

## 1. 产品决策：只保留一个原生窗口

正式窗口架构只有一个操作系统原生窗口，在窗口内切换：

1. **完整时钟（默认）**：视觉中心、直接启动、暂停、查看剩余时间。
2. **迷你时钟**：极小常驻窗口，仍可直接开始/暂停；可主动展开。
3. **任务抽屉**：由主窗口内部扩展出来，不打开第二个顶层窗口；管理任务后关闭。
4. **设置浮层**：同一窗口内模态内容，不创建独立顶层窗口。

同一时刻只出现一个可交互的主界面。切换形态不复制计时器、不重复绑定事件、不重建业务模型。

### 首次启动与重启

- 第一次启动：默认 25:00，未开始，没有当前任务，只有完整主时钟。
- 后续启动：恢复显示偏好（完整/迷你、透明度、置顶、窗口位置）及任务数据；**不在用户不知情的情况下自动开始新一轮计时**。
- 上次关闭时仍在运行的计时：按明确的后台运行/关闭策略恢复；默认不虚构完成记录。见技术文档计时恢复规则。
- 只允许一个应用实例；重复启动激活已有窗口，不生成第二个番茄钟。
- 初始主界面不展示产品标题栏、开发调试信息、独立大按钮或长任务列表。

## 2. 视觉方向：Crystal Timepiece（晶透时计）

设计不是“铺满毛玻璃”，而是用纯净的轮廓、克制的反射和精准的数字构成精致器件。

### 材质与配色

| 设计令牌 | 规格 | 用途 |
| --- | --- | --- |
| 墨松绿 | `#153E31` | 主时间数字 |
| 精工绿 | `#337259` | 运行进度环与激活图标 |
| 雾松灰 | `#81978B` | 次级文字 |
| 玻璃白 | `#F7FBF9` | 主体半透明基底 |
| 高光白 | `#FFFFFF`，透明度按场景 | 边缘高光，不叠加过度阴影 |
| 休息青绿 | `#4C7B87` | 休息状态 |
| 暂停暖灰 | `#8A8C83` | 暂停 |
| 分隔线 | `#D8E6DE` | 精细描边 |

- 默认材料为“清透玉质玻璃”：一层软质径向渐变、一条 1px 边缘高光、一条柔和环形阴影。
- 严禁厚重阴影、塑料质感、强玻璃折射、卡通番茄表情、装饰性发光粒子。
- 纹理与高光**不影响主文本对比度**。不依赖操作系统毛玻璃作为核心设计条件。
- 背景透明度默认 90%，范围 70%–100%，每档 5%。时间、交互图标和进度环不随背景整体透明。
- 黑色/复杂背景下必须保留足够的文字对比；必要时自动提高表盘内底色的不透明度。

### 字体

- 时间数字：推荐等宽数字，`FontFeature.tabularFigures()`，数字变化不得导致左右跳动。
- 主数字使用系统支持的清晰无衬线字体；不捆绑第三方商用字体。
- 中文系统字体回退：Ubuntu Noto Sans CJK / Windows Microsoft YaHei / macOS PingFang SC。
- 不允许缩放时截断冒号、时间数字、中文任务标题。

### 动效

- 表盘进度采用匀速连续角度插值，60Hz 绘制只在可见时工作；数字每秒变化。
- 开始/暂停状态切换 120–180ms 淡变，不能伴随界面跳跃。
- 形态切换 180–240ms，动画遵循“减少动态效果”系统偏好，可关闭。
- 完成轮次反馈不超过 700ms，无火花/烟花/长时间闪烁。
- 未运行、被遮挡、迷你等状态下限制重绘频率，禁止无意义持续高帧率占用。

## 3. 完整时钟：唯一的视觉中心

### 结构与尺寸

- 原生窗口建议 360×390 逻辑像素，按实际运行时窗口边框和 DPI 修正。
- 主圆表盘占约 290–310px 直径，居中，不在其背后出现第二套计时 UI。
- 进度环宽 5–6px，轨道低对比、已完成进度清楚。
- 时间数字 60–70sp，居中，横向完整呈现。
- 时间上方只显示一行状态（“专注中”“已暂停”“短休息”）。
- 时间下方只有一行任务名；无任务时显示“自由专注”，不要求任务预录入。
- 轮次圆点如保留，放在环内下部，尺寸 4–5px，并可在简约模式隐藏。

### 控件

常态一共只有 **4 个弱化的辅助图标**，布置在表盘外缘的固定位置：

1. 任务（列表图标）。
2. 设置（齿轮）。
3. 迷你/展开（对角箭头）。
4. 重置（回转箭头）。

- 置顶开关置于右键/更多菜单及设置中，不再让多个操作争夺表盘四周位置。
- 图标使用同一 20–22px 线条体系，实际鼠标/键盘点击目标不小于 40×40px。
- 图标平时低强调，悬停和键盘聚焦时显示背景及说明文字。
- 不出现单独的大“开始/暂停”按钮，也不出现第二套横向进度条。
- 窗口无传统重型标题栏，但必须有明确、与计时点击热区分离的可拖动区域。

### 中心唯一主操作

| 计时状态 | 中央主文案 | 单击中心结果 |
| --- | --- | --- |
| 未开始 | 25:00 / “点击开始” | 开始专注 |
| 专注中 | 24:18 / “专注中” | 暂停 |
| 暂停 | 24:18 / “已暂停 · 点击继续” | 继续 |
| 休息待开始 | 05:00 / “点击开始休息” | 开始休息 |
| 休息中 | 04:21 / “休息中” | 暂停休息 |
| 轮次结束 | 00:00 / “本轮完成” | 进入下一阶段的待开始状态 |

- 中心可点击热区至少 180×160px；单击触发、没有双击专属动作，以免第一击错误启动/暂停。
- 重置需使用边缘图标；正在计时或已经产生未完成进度时要求确认。
- 悬浮体拖动只能从外圈背景或专门拖动区域开始；不得与中心点击互相抢事件。
- 可用键盘 Space 开始/暂停、Esc 关闭浮层；必须有屏幕阅读器可见的“开始/暂停”语义。

## 4. 迷你时钟

- 默认 104×104 逻辑像素，实际窗口边界严格匹配（误差不超过 2px）。
- 仅显示紧凑时间、微型进度环及可主动展开入口；无标题栏、无底部大按钮。
- 中央单击与完整时钟一样是“开始/暂停/继续”，不得在迷你态重新定义为“展开”。
- 独立展开图标在右上角可见（悬停/键盘焦点更明显）；右键菜单亦可展开。
- 拖动从外环/非中心热区开始，位移阈值至少 6px；拖动不得误触发计时。
- 切换前后剩余时间误差不超过一个显示更新周期。
- 置顶状态、窗口位置、透明度由同一个窗口控制器管理，并在切换时保持。

## 5. 任务抽屉与设置

### 任务抽屉

- 从同一窗口内展开，整体可增至约 740×520；窄屏使用单栏覆盖抽屉。
- 任务管理沿用经验证的 V1.1 语义：点击标题选当前、复选框完成、搜索、拖动排序、已完成折叠、删除撤销。
- 任务可选，清单为空时仍可点击中央开始专注。
- 操作清单时计时不会自动暂停；若切换正在运行的当前任务，必须先暂停。
- 抽屉关闭后回到原时钟尺寸和焦点，不出现隐藏旧窗口。
- 50 项时仅内部列表滚动；“新增任务”和主计时入口固定可见。

### 设置浮层

按两个分组，不再出现大传统系统对话框：

- **计时**：专注 25 分钟、短休息 5 分钟、长休息 15 分钟；输入范围 1–180 分钟。
- **外观与行为**：玻璃背景透明度、始终置顶、默认迷你模式、是否提示完成。
- 提供“恢复默认设置”二级入口，有确认；修改透明度可实时预览，取消后回退。
- 当前计时不因设置而变化；新时长于下一次新轮次生效。

## 6. 关键平台约束

- 同一应用只能创建一个主窗口；打开任务与设置不能增加操作系统顶层窗口数量。
- Linux Wayland 不一定允许主动移动、任意置顶或全透明。平台能力不足时应优雅降级，不能假称置顶成功。
- Linux X11、Windows、macOS 按平台独立验收透明合成、置顶、缩放、窗口拖动与位置恢复。
- 没有 RGBA 合成的环境回退到不透明的“玻璃白”背景，文字必须始终清晰。
- 不实现鼠标点击穿透、常驻全屏叠加层、毛玻璃跨窗口截屏或屏幕内容捕获。

## 7. P0 / P1 / P2

**P0（上线门槛）**：单窗口启动、无任务可专注、中心点击启停、完整/迷你切换、任务入口、重置、计时状态稳定、存储不丢数据、平台窗口能力诚实反馈。

**P1（产品质感）**：精致圆环/高光材质、任务抽屉完整保留 V1.1 功能、透明度、可访问性、动画、系统主题/高 DPI 适配、窗口位置记忆。

**P2（不纳入当前正式版）**：复杂项目管理、标签/统计仪表盘、云同步、账户体系、背景毛玻璃、自由皮肤商店、点击穿透。

## 8. 产品验收清单

- [ ] 冷启动只有完整主表盘，没有重叠矩形、重复数字、重复图标。
- [ ] 无任务时中央单击立即开始 25 分钟；再点暂停；再点继续。
- [ ] 没有独立的大启停按钮；四个辅助图标符合统一线条风格。
- [ ] 完整/迷你切换后只存在一个原生主窗口，计时不跳变。
- [ ] 置顶开启后 X11/Windows/macOS 实测保持正确；Wayland 不支持时有明确反馈。
- [ ] 任务列表和设置在当前窗口内展开，不出现额外顶层窗口。
- [ ] 50 项任务浏览、完成、排序、搜索、撤销有效，计时不中断。
- [ ] 无任务时自由专注完成一次，应用总番茄 +1；任务番茄不得错误记入其他任务。
- [ ] 主时间可读性满足对比度要求，缩放 100%/125%/150%/200% 不裁字、不溢出。
- [ ] 完整/迷你、深色复杂桌面背景下表盘保持清晰，不出现黑方块或透明边缘锯齿。
- [ ] 启停响应无显著迟滞，窗口移动不误触发计时，整机 CPU/内存占用达技术验收门槛。
- [ ] 无网络也能启动、专注、保存；异常退出后的恢复状态可解释。
- [ ] 真实设备人工验收与自动化验收均完成后才标记“可发布”。

## 9. 与技术文档关系

产品文档规定 **用户看到什么、点击后发生什么、什么结果算合格**。窗口能力矩阵、状态机、数据格式、工程计划、持续集成、回滚和量化质量门槛，参见《青番 V2 技术架构与研发验收标准》。
