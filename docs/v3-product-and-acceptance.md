# 青番 V3｜产品行为与验收基线

状态：PR #4 的候选重构，不作为 main 正式版本。

## 设计原则

一个 104 逻辑像素圆形时钟、两个时间阶段：**专注**与**休息**。显示永远只包含 **MM:SS 倒计时和环形进度**。不展示任务名称、阶段名称、状态文案、四轮指示点，不存在大/小表盘切换。

鼠标悬停圆形时钟时，以标准 **播放 / 暂停** 图标呈现专注控制，并提供清单和更多菜单入口；移开后隐藏操作图标。任务面板内同一圆形时钟始终保持 104px，不被放大。Windows 的原生 HWND 可为满足最小宽度限制而包含透明留白，但实际画出的圆盘不能变大。

## 时间状态机

| 当前 | 事件 | 下一状态 | 记录 |
| --- | --- | --- | --- |
| 专注待开始 | 点击播放/任务面板“开始专注” | 专注运行中 | 不新增 |
| 专注运行中 | 点击暂停 | 专注已暂停 | 不新增 |
| 专注已暂停 | 点击播放 | 专注运行中 | 不新增 |
| 专注运行中 | 倒计时归零 | **休息自动运行中** | 完成轮数与当前任务番茄数各 +1，至多一次 |
| 休息运行中 | 倒计时归零 | **新一轮专注待开始** | 不新增 |
| 休息运行中 | 任务面板点击“开始专注” | **新的专注运行中** | 不新增 |
| 休息运行中 | 点击表盘、按空格、右键菜单 | 仍为休息运行中 | 无暂停、无跳过控件 |
| 休息运行中 | 仅选择/整理任务 | 仍为休息运行中 | 不变 |

默认专注 25 分钟，休息 5 分钟；偏好设置只有这两个时间参数，修改即时持久化，当前运行中的剩余时间不跳变。无长短休息或四轮特殊周期。

计时基于单调时钟；集中处理阶段完成和防重复计数。超过截止时间的迟到轮询需把超时部分计入休息，不能因此延长休息。应用重启：未完成专注恢复剩余时间但暂停；休息直接恢复到新一轮专注待开始；已完成轮次和任务均保留。

旧 V2 的 `shortBreakMinutes` 迁移为 V3 的 `restMinutes`；`shortBreak`、`longBreak` 均识别为旧休息，恢复为全新专注待开始。V2 的数据文件继续在原位置使用，保留任务和已完成次数。

## 界面

- **时钟**：仅 104px 圆形晶透材质；专注与休息可由环颜色低对比度区分。正常状态只能看到数字和进度环。
- **时钟悬停**：清单、更多；专注期间显示播放或暂停图标。休息期间不显示播放/暂停。时钟外圈拖动窗口，中央数字可点击控制专注。
- **任务面板**：小圆形时钟 + 清单区域，待办、搜索、完成、撤销、排序、重命名、删除。主要操作统一为“开始专注”（已在专注中则可显示“返回专注”）。选择任务不启动工作。
- **偏好设置**：专注时间、休息时间、背景透明度，自动保存。
- **更多菜单**：偏好设置、专注中的“重新开始本轮”、始终置顶/取消置顶；休息期间不显示重置专注，也不出现“跳过休息”。
- **窗口**：同一原生顶层窗口；折叠只显示小表盘，展开后左侧小表盘固定大小、右侧任务或设置；不创建新应用实例。

## 验收门槛

1. 104px 圆盘在 100/125/150/200% 缩放和展开面板中尺寸一致，无布局溢出；
2. 中心不显示任务名/状态名，非悬停不显示动作控件；播放/暂停符合系统惯例；
3. 专注归零立刻自动运行休息，休息不可暂停，休息归零回到**暂停等待手动开始**的新专注；
4. 任务选择不结束休息，但“开始专注”立即结束休息并运行新的完整专注；
5. 轮次只记一次，退出重启不重复记数，V2 任务数据及番茄数保留；
6. Ubuntu、Windows、macOS 分别进行 Flutter 分析/测试、原生 Release、窗口检查和安装包/DMG 验收；
7. PR 保持 Draft，不能以云端 CI 取代全部真实物理桌面测试。
